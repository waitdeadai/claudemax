# _moc/ — maps of content (human navigation only)

Optional human-authored maps-of-content linking related decisions and facts for
your own navigation in Obsidian. Never compiled, never read by agents, never
promoted into sqlite or CLAUDE.md. Pure editorial scaffolding for the human
maintainer.

Use these to group, for example, all auth-related decisions, or to keep a running
index of the harness's load-bearing invariants. Dataview queries are fine here —
they only run in your Obsidian editor.
